# Gemini thoughtSignature API Contract

**Source**: [ai.google.dev/gemini-api/docs/thought-signatures](https://ai.google.dev/gemini-api/docs/thought-signatures)

## What It Is

An opaque, encrypted bytes field (base64-encoded in JSON) returned on `Part`
objects in Gemini API responses. It is a stateful session cookie for the model's
chain-of-thought reasoning.

- **Proto type**: `bytes`
- **JSON type**: `string` (base64-encoded)
- **Cannot be decoded** — intentionally opaque
- **Ephemeral per-turn** — valid only for immediate conversation continuation

## Where It Appears

```
GenerateContentResponse
  -> Candidate
       -> Content
            -> Part[]
                 ├── text              (string)
                 ├── functionCall      (FunctionCall)
                 ├── thought           (bool)          <- marks thinking part
                 └── thoughtSignature  (bytes/string)  <- co-located with its part
```

## Model-Specific Behavior

| Model | Returns signature? | Enforcement |
|-------|-------------------|-------------|
| Gemini 3.x Pro / Flash / 3.1 Pro | Yes, always (FC + last text part) | **Strict** — 400 on missing |
| Gemini 3 Pro Image | Yes, first + every inlineData part | **Strict** |
| Gemini 2.5 Pro / Flash (thinking) | Yes, on first Part | **Relaxed** — no error if omitted |
| Gemini 2.0 Flash Thinking | No | N/A |

## Round-Trip Contract

If you receive a `thoughtSignature`, echo it back **unchanged** in the **same
Part position** when replaying history.

### Sequential function calls

Each step in a multi-step chain gets its own signature. ALL must be present:

```json
[
  { "role": "user", "parts": [{ "text": "Book flight..." }] },
  {
    "role": "model",
    "parts": [{
      "functionCall": { "name": "check_flight", "args": { "flight": "AA100" } },
      "thoughtSignature": "<Signature_A>"
    }]
  },
  { "role": "user", "parts": [{ "functionResponse": { ... } }] },
  {
    "role": "model",
    "parts": [{
      "functionCall": { "name": "book_taxi", "args": { ... } },
      "thoughtSignature": "<Signature_B>"
    }]
  }
]
```

### Parallel function calls

Signature appears on **first** functionCall Part only.

### Hard constraints

1. Return signature inside its original Part — never detach
2. Never merge a signed Part with an unsigned Part
3. Never merge two signed Parts
4. Parallel function responses must be batched together

## Error When Missing

```
HTTP 400 INVALID_ARGUMENT
"Function call `<name>` in the `<N>th` content block is missing a `thought_signature`."
```

## Bypass Sentinels

For injected function calls not generated by Gemini:

```
"skip_thought_signature_validator"   (string)
"context_engineering_is_the_way_to_go" (string)
```

These skip validation but degrade model performance. Last resort only.
